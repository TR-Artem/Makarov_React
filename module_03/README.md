# Модуль 3 · Мониторинг сайтов группы

- Код: https://github.com/TR-Artem/Makarov_Veb
- Сайт: https://tr-artem.github.io/Makarov_Veb/
- Прямая ссылка: https://tr-artem.github.io/Makarov_Veb/site/staryy

## Выполненные требования

- Маршруты `/`, `/site/:id`, `/about`, `*`; меню на `NavLink` с подсветкой текущей страницы.
- Главная: сводка «Не открываются: N из M» и карточки со статусом последней проверки, карточка ведёт на страницу сайта.
- Страница сайта: название, адрес, «Открывался в N из M», таблица истории с выделенными сбоями.
- Несуществующий `id` — сообщение и ссылка на главную.
- Загрузка `sites.json` и `results.json` в `MonitoringProvider`, страницы и шапка читают хуком `useMonitoring`.
- Загрузка и ошибка с кодом ответа; `base`, `basename` и копия `404.html` для прямых ссылок.
- Ночная проверка `check.yml`: 00:00 МСК, коммит бота с `results.json`, публикация через `workflow_call`.
- Telegram: сообщение только при изменениях; токен и чат — в секретах репозитория.

## Осталось

- Заменить примеры в `public/data/sites.json` на сайты группы.
- Добавить секреты `TELEGRAM_TOKEN` и `TELEGRAM_CHAT_ID`.
- `ai-log.md` ведётся отдельно.
