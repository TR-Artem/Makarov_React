### Запрос 1. Заказчику нужны резюме с ожиданиями по зарплате от 100 000 ₽ и выше.

```js
db.resumes.find({ salary: { $gte: "100000" } })
```

- Решение: есть ошибка — значение не того типа: строка вместо числа или логического значения — верно
- Комментарий: В поле salary числа, а в фильтре строка "100000". Сравнение $gte между числом и строкой не даёт совпадений — отсюда ноль. Нужно число без кавычек: { salary: { $gte: 100000 } } — 4 резюме.
- Исправленный запрос:

```js
{ salary: { $gte: 100000 } }
```

### Запрос 2. Найти кандидатов с высшим образованием.

```js
db.resumes.find({ education: { level: "Высшее" } })
```

- Решение: есть ошибка — вложенный документ сравнивается целиком — нужна точечная нотация — верно
- Комментарий: { education: { level: "Высшее" } } требует точного совпадения всего документа education, а в нём ещё place и year. Нужна точечная нотация: { "education.level": "Высшее" } — 4 резюме.
- Исправленный запрос:

```js
{ "education.level": "Высшее" }
```

### Запрос 3. Кандидаты, которые знают и SQL, и Python.

```js
db.resumes.find({ skills: { $in: ["SQL", "Python"] } })
```

- Решение: есть ошибка — не тот оператор для массива: $in вместо $all или наоборот — верно
- Комментарий: $in берёт документы, где в skills есть хотя бы один из навыков, поэтому попали Анна Белова и Марк Ефремов с одним Python. Нужны оба навыка: { skills: { $all: ["SQL", "Python"] } } — 4 резюме.
- Исправленный запрос:

```js
{ skills: { $all: ["SQL", "Python"] } }
```

### Запрос 4. Кандидаты, которые проработали в Retail Lab не меньше 12 месяцев.

```js
db.resumes.find({ "experience.company": "Retail Lab", "experience.months": { $gte: 12 } })
```

- Решение: есть ошибка — условия на массив документов выполняются в разных элементах — нужен $elemmatch — верно
- Комментарий: Два условия через точку проверяются по массиву независимо: у Алины Дроздовой Retail Lab — 5 месяцев, а 14 месяцев — в Ozon. Нужен $elemMatch, чтобы оба условия относились к одной работе. Такого кандидата нет.
- Исправленный запрос:

```js
{ experience: { $elemMatch: { company: "Retail Lab", months: { $gte: 12 } } } }
```

```js
{ city: "Москва", is_open: true, "salary.to": { $gte: 160000 } }
```

### Запрос 6. Все резюме на должности, в названии которых есть слово Python.

```js
db.resumes.find({ position: /python/ })
```

