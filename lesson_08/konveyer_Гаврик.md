## Письмо 1. Ревью конвейеров

### 1. Выручка доставленных заказов от ноутбуков.

- Решение: есть ошибка — сумма по полю заказа после $unwind — итог повторён в каждой позиции — верно
- Комментарий: После $unwind поле total всего заказа повторено в каждой позиции. Сумма total по позициям-ноутбукам складывает итоги заказов целиком, вместе с другими товарами, и заказ с двумя ноутбуками считает дважды. Выручку позиции даёт $multiply количества и цены: { $sum: { $multiply: ["$items.qty", "$items.price"] } }.
- Исправленный конвейер:

```js
[
  { $match: { status: "доставлен" } },
  { $unwind: "$items" },
  { $match: { "items.category": "ноутбуки" } },
  { $group: { _id: null, revenue: { $sum: { $multiply: ["$items.qty", "$items.price"] } } } }
]
```

### 2. Сколько заказов в пути в каждом городе.

- Решение: есть ошибка — $project перед стадией, которой нужно отброшенное поле — верно
- Комментарий: $project оставил только number и delivery, поэтому в $match не дошло поле status и условие не выполнилось ни у одного документа. Отбор ставят до $project или оставляют status в проекции.
- Исправленный конвейер:

```js
[
  { $match: { status: "в пути" } },
  { $group: { _id: "$delivery.city", orders: { $sum: 1 } } },
  { $sort: { _id: 1 } }
]
```

### 3. Номер первого по дате заказа каждого покупателя из трёх: c-007, c-011, c-018.

- Решение: есть ошибка — $first или $last без $sort перед $group — верно
- Комментарий: Без $sort документы в $group идут в порядке хранения, и $first берёт заказ с наименьшим номером, а не с самой ранней датой. Нужен $sort по created до $group; сортировка по _id после группировки остаётся для порядка результата.
- Исправленный конвейер:

```js
[
  { $match: { customer_id: { $in: ["c-007", "c-011", "c-018"] } } },
  { $sort: { created: 1 } },
  { $group: { _id: "$customer_id", first: { $first: "$number" } } },
  { $sort: { _id: 1 } }
]
```

### 4. Пять самых дорогих доставленных заказов.

- Решение: есть ошибка — стадии стоят не в том порядке: $limit срабатывает раньше отбора — верно
- Комментарий: $limit отрезал пять самых дорогих заказов любого статуса, и $match нашёл среди них только два доставленных. $match ставят до $sort и $limit — тогда предел берёт пять из доставленных.
- Исправленный конвейер:

```js
[
  { $match: { status: "доставлен" } },
  { $sort: { total: -1 } },
  { $limit: 5 },
  { $project: { _id: 0, number: 1, total: 1 } }
]
```

### 5. Выручка доставленных заказов по способам оплаты.

- Решение: есть ошибка — путь к полю записан без знака $ — верно
- Комментарий: Без знака $ строка "payment.method" — один и тот же текст у всех документов, поэтому все заказы попали в одну группу. Путь к полю пишется "$payment.method".
- Исправленный конвейер:

```js
[
  { $match: { status: "доставлен" } },
  { $group: { _id: "$payment.method", revenue: { $sum: "$total" } } },
  { $sort: { _id: 1 } }
]
```

### 6. Сколько штук смартфонов продано в доставленных заказах.

- Решение: есть ошибка — условие на элемент массива проверено до $unwind — проходят заказы целиком — верно
- Комментарий: Условие на items.category до $unwind отбирает заказы, в которых есть смартфон, и заказ проходит со всеми позициями: в сумму попали штуки других товаров. То же условие повторяют после $unwind.
- Исправленный конвейер:

```js
[
  { $match: { status: "доставлен", "items.category": "смартфоны" } },
  { $unwind: "$items" },
  { $match: { "items.category": "смартфоны" } },
  { $group: { _id: null, qty: { $sum: "$items.qty" } } }
]
```

### 7. Средний чек доставленных заказов в каждом городе, округлённый до рубля, по убыванию.

- Решение: конвейер верный — верно
- Комментарий: Конвейер верный: отбор до группировки, среднее по сумме заказа, $round в $project и сортировка по готовому полю avg.
- Исправленный конвейер:

```js
[
  { $match: { status: "доставлен" } },
  { $group: { _id: "$delivery.city", avg: { $avg: "$total" } } },
  { $project: { avg: { $round: ["$avg", 0] } } },
  { $sort: { avg: -1 } }
]
```

### 8. Три самых продаваемых по штукам товара в доставленных заказах.

- Решение: конвейер верный — верно
- Комментарий: Конвейер верный: штуки — поле позиции, поэтому сначала $unwind; второй ключ сортировки _id делает порядок при равенстве однозначным.
- Исправленный конвейер:

```js
[
  { $match: { status: "доставлен" } },
  { $unwind: "$items" },
  { $group: { _id: "$items.title", qty: { $sum: "$items.qty" } } },
  { $sort: { qty: -1, _id: 1 } },
  { $limit: 3 }
]
```

## Письмо 4. Свои конвейеры

### 1. Доставленные заказы по способу доставки: _id — способ (delivery.type), orders — число заказов, revenue — выручка. По убыванию revenue.

```js
db.orders.aggregate([{ $match: { status: "доставлен" } }, { $group: { _id: "$delivery.type", orders: { $sum: 1 }, revenue: { $sum: "$total" } } }, { $sort: { revenue: -1 } }])
```

- Результат совпадает с нужным, запусков: 2

### 2. Коллекция products. Средняя цена товаров каждой категории, округлённая до рубля: _id — категория, avg — средняя цена. По возрастанию avg.

```js
db.products.aggregate([{ $group: { _id: "$category", avg: { $avg: "$price" } } }, { $project: { avg: { $round: ["$avg", 0] } } }, { $sort: { avg: 1 } }])
```

- Результат совпадает с нужным, запусков: 2

### 3. Покупатели, у которых сумма доставленных заказов больше 400 000: _id — customer_id, spent — сумма. По убыванию spent.

```js
db.orders.aggregate([{ $match: { status: "доставлен" } }, { $group: { _id: "$customer_id", spent: { $sum: "$total" } } }, { $match: { spent: { $gt: 400000 } } }, { $sort: { spent: -1 } }])
```

- Результат совпадает с нужным, запусков: 2

### 4. Для каждого города — массив номеров отменённых заказов по возрастанию номера: _id — город, numbers — массив. Города по алфавиту.

```js
db.orders.aggregate([{ $match: { status: "отменён" } }, { $sort: { number: 1 } }, { $group: { _id: "$delivery.city", numbers: { $push: "$number" } } }, { $sort: { _id: 1 } }])
```

- Результат совпадает с нужным, запусков: 2

### 5. Одним запросом по доставленным заказам: в поле total — массив из одного документа { orders: число заказов }, в поле top — три товара с наибольшим числом штук (_id — название, qty — штуки), по убыванию qty, при равенстве — по названию.

```js
db.orders.aggregate([{ $match: { status: "доставлен" } }, { $facet: { total: [{ $count: "orders" }], top: [{ $unwind: "$items" }, { $group: { _id: "$items.title", qty: { $sum: "$items.qty" } } }, { $sort: { qty: -1, _id: 1 } }, { $limit: 3 }] } }])
```

- Результат совпадает с нужным, запусков: 2
