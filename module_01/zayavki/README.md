# Доска заявок общежития

Модуль 1: React + TypeScript + Vite.

- `src/requests.ts` — типы и начальные заявки.
- `src/storage.ts` — сохранение списка в `localStorage`.
- `src/notify.ts` — отправка заявки на вебхук n8n.
- `src/App.tsx` — состояние, фильтр, обработчики, сообщение над списком.
- `src/components/` — шапка, форма и карточка.

```
npm install
npm run dev
npm run build
npm run lint
```
