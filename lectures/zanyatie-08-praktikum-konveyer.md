## Содержание практикума

Практикум закрепляет модуль 4 справочника на базе `shop`. Работа идёт
в браузере: аналитик отдела, который собирает витрину продаж, получает
от руководителя четыре письма.

| Письмо | Что отрабатывает |
|---|---|
| 1 · ревью | восемь конвейеров коллег: шесть с ошибками из глав модуля и два верных; вид ошибки, комментарий, исправленный конвейер |
| 2 · сборка | пять заявок руководителей: конвейер собирается из готовых стадий, в наборе есть лишние и почти верные стадии |
| 3 · предсказание | пять конвейеров по восьми заказам одного покупателя: результат выбирается из четырёх вариантов без запуска |
| 4 · свой конвейер | пять задач без заготовок, от `$group` до `$facet` с двумя ветками |

После запуска конвейера видно, сколько документов вышло из каждой стадии.
Конвейеры выполняются в браузере на копии базы `shop`; результаты и коды
ошибок сверены с сервером стенда курса, MongoDB 7. К любому открытому письму
можно вернуться до сдачи. После кнопки «Сдать работу» открывается рецензия
руководителя с баллами и разбором.

## Термины

| Термин | Значение |
|---|---|
| конвейер агрегации | список стадий; документы проходят стадии сверху вниз, каждая стадия получает выход предыдущей |
| `$match`, `$sort`, `$limit`, `$skip` | отбор документов по условию, сортировка, первые N документов, пропуск первых N документов |
| `$project`, `$addFields`, `$set`, `$unset` | выбор полей документа, добавление вычисляемых полей, удаление полей |
| `$group` и аккумуляторы | группировка по `_id`; `$sum`, `$avg`, `$min`, `$max`, `$push`, `$addToSet`, `$first`, `$last` считают значение по документам группы |
| `$unwind` | один документ на каждый элемент массива; путь к массиву начинается с `$` |
| `$bucket`, `$facet` | раскладка документов по диапазонам значений; несколько конвейеров по одним и тем же документам |
| `$replaceRoot`, `$redact` | замена документа вложенным документом; удаление частей документа по условию |
