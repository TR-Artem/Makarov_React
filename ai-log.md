# Журнал работы с ИИ · модули 2 и 3

Дисциплина «Фронтенд в эпоху ИИ». Ноябрь 2026.
Модуль 2 — проект «Доска заявок общежития» и ИИ-диспетчер. Модуль 3 — монитор сайтов и оповещение.

| Дата | Вопрос | Что взял из ответа | Что не взял и почему |
| --- | --- | --- | --- |
| 19.11 | Почему на карточке «В работе» не видно, кто взял заявку? | В базовом варианте такого поля нет, это дополнительное задание П2: поле `master`, запись имени в узле «Статус в базу», показ на карточке | Хранить имя только в n8n: доска читает базу, без поля в коллекции имя не дойдёт |
| 19.11 | Почему после нажатия «Взять» статус меняется, а имя не появляется? | В узле «Статус в базу» отправлялся только `{ status }`, нужно добавить `master` из узла «Кто и что нажал» | Отправлять `master` из тела вебхука: там его нет, имя знает только нажатие в Telegram |
| 19.11 | Почему в таблице дайджеста в колонке `tags` оказались ссылки? | В шапке не хватало седьмого заголовка `link`, значения сдвинулись; после правки шапки и новой версии развертывания поля стали на места | Менять порядок колонок в скрипте под текущую шапку — тогда шапка и код разойдутся в следующей сдаче |
| 19.11 | Почему n8n выполнял процесс, но категория в базе не менялась? | Сначала не разрешалось имя `pocketbase` из контейнера, потом процесс падал на `PATCH`; проверка по журналу запусков показала причину | Менять адрес коллекции в процессе — коллекция была верной |
| 19.11 | Почему модель поставила «Электрика» для протекающей батареи? | Маленькая модель `qwen2.5:3b` иногда повторяет категорию автора; в методичке это разобрано, категорию исправляет мастер | Убирать категорию автора из запроса: тогда теряется подсказка для остальных заявок |
| 19.11 | Почему после ночной проверки сайт показывал старое время? | GitHub Pages кэширует файлы на 10 минут; для `results.json` добавил параметр в адресе, чтобы данные приходили свежими | Отключать кэш для всех файлов: для статики это лишние запросы |
| 19.11 | Почему публикация упала, хотя артефакт собрался? | `deploy-pages` не увидел уже загруженный артефакт — сбой на стороне GitHub; перезапуск задания прошёл | Переписывать конвейер: ошибка не в нём |
| 19.11 | Почему прямая ссылка на страницу сайта на Pages открывается с кодом 404? | Pages отдаёт `404.html`, а `BrowserRouter` с `basename` показывает нужную страницу; код ответа при этом остаётся 404 | Делать редирект на главную: адрес страницы должен сохраняться |
| 19.11 | Почему Ollama была доступна только с компьютера? | По умолчанию слушает `127.0.0.1`; для запросов из контейнера n8n нужен `0.0.0.0` | Открывать порт всем без ограничений в интернете — стенд локальный |
| 19.11 | Почему процесс n8n был «активен», но не запускался по вебхуку? | В n8n 2.x одного флага `active` мало: нужна публикация версии процесса | Оставлять `active` без публикации — вебхук не регистрируется |
