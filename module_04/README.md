# Модуль 4 · Дайджест новостей

- Код: https://github.com/TR-Artem/digest
- Сайт: https://tr-artem.github.io/digest/

## Что сделано

- Vite + React + TypeScript, адрес данных в `VITE_DIGEST_URL` (`.env`), в коде строки нет.
- Карточка: заголовок ссылкой в новой вкладке, источник, дата и время, пересказ, теги метками.
- Новости от свежих к старым.
- Поиск по заголовку и пересказу без учёта регистра, выбор тега, флажок «Только непрочитанные»; отфильтрованный список вычисляется при отрисовке.
- Отметка «прочитано» снимается повторным нажатием, хранится в `localStorage` (ключ `digest-read`).
- Сообщения: `role="status"` при загрузке, `role="alert"` с кодом при ошибке, «Новостей не найдено».
- 11 тестов с подменённым `fetch`, `npm run lint -- --deny-warnings` и тесты в `deploy.yml`.
- Lighthouse: доступность 100, SEO 100, best practices 100.
- `AGENTS.md`, `tasks/01-zagruzka.md`, `tasks/02-filtry.md`, `tasks/03-prochitano.md`, `ai-log.md`.

## Автоматизация

`avtomatizaciya/` — код Apps Script, два процесса n8n и стенд. Инструкция в `avtomatizaciya/README.md`.

## Проверка автоматизации

Прогнано на настоящей Google Таблице через веб-приложение Apps Script:

- «Дайджест: сбор новостей» — 15 новостей из трёх лент, пересказ и теги от модели, запись в таблицу; повторный запуск не дублирует строки;
- «Дайджест: вечером в Telegram» — одно сообщение со списком новостей за сутки, Telegram ответил `ok: true`;
- сайт читает ту же таблицу: 15 карточек, теги и ссылки на месте.

Адрес веб-приложения записан в `VITE_DIGEST_URL` в `.env` проекта `digest`. Ключ записи `KEY` хранится только в свойствах Apps Script и в локальном `.env`, в репозиторий не попадает.
