# Автоматизация модуля 4 · Дайджест

Утро: RSS → модель → Google Таблица. Вечер: таблица → сообщение в Telegram.

## 1. Таблица

1. Открыть sheets.new, назвать «Дайджест новостей», лист — `news`.
2. В первую строку A1:G1: `id`, `date`, `source`, `title`, `summary`, `tags`, `link`.

## 2. Apps Script

1. В таблице: Расширения → Apps Script, проект «Дайджест».
2. Вставить `apps-script.gs` в `Код.gs`, сохранить.
3. Настройки проекта → Свойства скрипта → `KEY` = длинная случайная строка.
4. Начать развертывание → Новое развертывание → Веб-приложение:
   - запуск от имени владельца, доступ «Все»;
   - скопировать адрес, заканчивающийся на `/exec`.
5. Проверить: `curl -sL АДРЕС` — ответ `{"news":[]}`.

## 3. Стенд n8n

```
cp .env.example .env      # DIGEST_URL, DIGEST_KEY, TELEGRAM_TOKEN, TELEGRAM_CHAT_ID
docker compose up -d
```

Ollama — на компьютере: `ollama pull qwen2.5:3b`, затем `ollama serve`.
Из контейнера n8n модель доступна по `http://host.docker.internal:11434`.

## 4. Процессы

Импорт: n8n → новый процесс → вставить JSON в холст (Ctrl+V).

| Файл | Когда | Что делает |
| --- | --- | --- |
| `n8n/digest-collect.json` | 8:00 | читает три ленты, оставляет свежие за сутки, пересказывает моделью, пишет в таблицу |
| `n8n/digest-telegram.json` | 19:00 | читает таблицу, собирает новости за сутки в одно сообщение, отправляет в Telegram |

Проверка: «Запустить вручную» → «Execute workflow». В таблице появятся строки, в Telegram — сообщение.

## 5. Сайт

В репозитории `digest` в `.env` заменить `VITE_DIGEST_URL` на адрес веб-приложения и запушить.
Сейчас там демо-файл `https://tr-artem.github.io/digest/demo/news.json`.

## Секреты

`DIGEST_KEY` и `TELEGRAM_TOKEN` — только в `.env`, в репозиторий не попадают.
